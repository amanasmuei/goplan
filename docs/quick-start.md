# GoPlan Quick Start Guide

*Get up and running with GoPlan in 5 minutes*

## Step 1: Sign In (30 seconds)

1. Go to `https://goplan.yourcompany.com`
2. Click **"Sign In"**
3. Enter your company credentials
4. You're in!

## Step 2: Explore Your Dashboard (1 minute)

After logging in, you'll see your Dashboard:

```
┌─────────────────────────────────────────────────────────┐
│  GoPlan                          [+ New Task] [👤]   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  📋 My Tasks          📊 Analytics      ⚙️ Settings     │
│                                                         │
│  ┌─────────────────┐  ┌─────────────────┐              │
│  │ Pending    (3)  │  │ In Progress (2) │              │
│  │ • Review PR     │  │ • API Feature   │              │
│  │ • Write docs    │  │ • Bug fix       │              │
│  │ • Team meeting  │  └─────────────────┘              │
│  └─────────────────┘                                   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

- **My Tasks**: Your assigned tasks organized by status
- **Analytics**: Your productivity insights
- **+ New Task**: Create a new task

## Step 3: Create Your First Task (2 minutes)

1. Click **"+ New Task"** in the top-right corner

2. Fill in the details:
   - **Title**: `Complete onboarding checklist`
   - **Description**: `Review company policies and complete setup`
   - **Priority**: Medium
   - **Due Date**: Tomorrow

3. Click **"Create Task"**

GoPlan's AI will automatically generate:
- A predicted completion time
- Suggested scheduling

## Step 4: Acknowledge and Start (1 minute)

1. Click on your new task to open it

2. Review the AI prediction:
   ```
   ┌────────────────────────────────────────┐
   │  AI Prediction: 45 minutes            │
   │  Based on: Similar tasks, your history │
   │                                        │
   │  [Accept] [Adjust Estimate]            │
   └────────────────────────────────────────┘
   ```

3. Click **"Accept Prediction"** (or adjust if needed)

4. Click **"Acknowledge & Continue"**

5. Click **"Start Working"** to begin

## Step 5: Complete Your Task (30 seconds)

When finished:

1. Click **"Complete Task"**

2. Enter the actual time taken:
   ```
   ┌────────────────────────────────────────┐
   │  Predicted: 45 minutes                │
   │  Actual time: [40] minutes            │
   │                                        │
   │  [Complete]                            │
   └────────────────────────────────────────┘
   ```

3. Click **"Complete"**

Congratulations! You've completed your first GoPlan workflow!

## Key Shortcuts

| Action | How |
|--------|-----|
| New task | Press `N` or click **+ New Task** |
| Search | Press `S` or click the search icon |
| Help | Press `?` for all shortcuts |
