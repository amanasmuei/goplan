# GoPlan User Guide

## Introduction

GoPlan is an intelligent task management platform that uses AI to help you track, manage, and optimize your work. This guide will walk you through all the features and how to use them effectively.

## Getting Started

### Logging In

1. Navigate to GoPlan at `https://goplan.yourcompany.com`
2. Click "Sign In" and authenticate with your company credentials
3. You'll be redirected to your Dashboard

### Understanding the Dashboard

The dashboard provides an overview of your tasks and productivity metrics:

- **My Tasks**: Tasks assigned to you, organized by status
- **Recent Activity**: Timeline of recent task updates
- **Productivity Insights**: AI-generated suggestions to improve your workflow
- **Team Overview**: Summary of team progress (if applicable)

## Working with Tasks

### Creating a New Task

1. Click the **"+ New Task"** button in the header
2. Fill in the task details:
   - **Title**: A clear, descriptive name for the task
   - **Description**: Detailed information about what needs to be done
   - **Priority**: Low, Medium, High, or Urgent
   - **Due Date**: When the task should be completed
   - **Estimated Time**: Your estimate for how long it will take
3. Click **"Create Task"**

GoPlan's AI will automatically:
- Generate a predicted completion time based on similar tasks
- Suggest potential blockers or dependencies
- Recommend optimal scheduling

### Understanding Task States

Tasks flow through several states during their lifecycle:

| State | Description |
|-------|-------------|
| **Pending** | Task has been created but not started |
| **Acknowledged** | You've reviewed the AI predictions and accepted the task |
| **In Progress** | You're actively working on the task |
| **Blocked** | Task is waiting on something (dependency, information, etc.) |
| **Review** | Task is complete and awaiting review |
| **Completed** | Task has been finished and reviewed |
| **Cancelled** | Task has been cancelled and won't be completed |

### Acknowledging a Task

When a new task is assigned to you:

1. Review the task details and AI predictions
2. Click **"Acknowledge Task"**
3. Review the predicted completion time
4. Either:
   - **Accept Prediction**: Agree with the AI's estimate
   - **Adjust**: Modify the estimate based on your knowledge
5. Click **"Acknowledge & Continue"**

This acknowledgment helps GoPlan learn from your feedback and improve future predictions.

### Updating Task Progress

While working on a task:

1. Open the task by clicking on it
2. Add progress notes in the **Activity** section
3. Update the status as needed:
   - Click **"Start Working"** to move to In Progress
   - Click **"Mark Blocked"** if you encounter an obstacle
   - Click **"Submit for Review"** when complete

### Completing a Task

When you finish a task:

1. Click **"Complete Task"** or **"Submit for Review"**
2. Fill in the completion details:
   - **Actual Time**: How long the task actually took
   - **Notes**: Any relevant information about the completion
   - **Variance Explanation**: If actual time differs significantly from estimate
3. Click **"Submit"**

GoPlan will analyze the variance between estimated and actual time to improve future predictions.

## Task Filtering and Search

### Using Filters

The task list supports multiple filters:

- **Status**: Filter by task state
- **Priority**: Filter by urgency level
- **Date Range**: Filter by due date or creation date
- **Assignee**: Filter by who the task is assigned to

Click **"Filters"** to expand the filter panel and select your criteria.

### Searching Tasks

Use the search bar to find tasks by:
- Title
- Description
- Tags
- ID

The search supports partial matches and updates in real-time.

## Analytics and Insights

### Personal Analytics

Access your productivity metrics from the **Analytics** page:

- **Completion Rate**: Percentage of tasks completed on time
- **Average Variance**: How accurately you estimate task times
- **Productivity Trends**: Your output over time
- **Focus Areas**: Where you spend most of your time

### Team Analytics (Team Leads)

Team leads can view aggregated team metrics:

- **Team Velocity**: Tasks completed per sprint/week
- **Bottlenecks**: Common blocking issues
- **Workload Distribution**: How work is spread across the team

## Notifications

### Notification Types

GoPlan sends notifications for:
- New task assignments
- Task status changes
- Approaching deadlines
- AI-generated insights and suggestions

### Managing Notifications

1. Click your profile icon in the top-right
2. Select **"Settings"**
3. Navigate to **"Notifications"**
4. Toggle notification preferences on/off

## Keyboard Shortcuts

Speed up your workflow with these shortcuts:

| Shortcut | Action |
|----------|--------|
| `N` | Create new task |
| `S` | Open search |
| `F` | Toggle filters |
| `1-5` | Set priority (1=Low, 5=Urgent) |
| `Enter` | Open selected task |
| `Esc` | Close modal/panel |
| `?` | Show all shortcuts |

## Best Practices

### For Accurate Estimates

1. Break large tasks into smaller sub-tasks
2. Review AI predictions and adjust based on context
3. Factor in meetings and interruptions
4. Learn from past variance data

### For Effective Task Management

1. Update task status promptly
2. Add meaningful progress notes
3. Use tags to categorize related tasks
4. Review your analytics weekly

### For Team Collaboration

1. Assign tasks clearly with all necessary context
2. Use comments for async communication
3. Keep dependencies updated
4. Celebrate completions!

## Troubleshooting

### Task Won't Update

- Check your internet connection
- Refresh the page
- If the issue persists, contact support

### AI Predictions Seem Off

- Review and adjust predictions regularly
- The AI learns from your feedback over time
- Ensure you're completing tasks and marking actual times

### Can't Find a Task

- Check all status filters are enabled
- Use the search function
- Verify you have access to the task
