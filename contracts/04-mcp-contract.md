# MCP (Model Context Protocol) Contract

> This document defines the MCP interface between AI agents and the GoPlan system.

## Design Principles

1. **AI never writes directly** - All mutations go through approval workflow
2. **Explicit intent** - No hidden inference; confidence scoring required
3. **Deterministic schema** - Machine-readable, testable outputs
4. **Human-in-the-loop** - User approval required for all write operations
5. **Full auditability** - Every action logged with context

---

## Intent Envelope Schema

Every AI request MUST resolve into this structure:

```typescript
interface MCPIntentEnvelope {
  intentId: string;                    // UUID, generated by system
  intentType: IntentType;
  confidence: number;                  // 0.0 - 1.0
  needsClarification: boolean;
  clarificationQuestion?: string;
  source: 'chat' | 'ui' | 'api';
  actor: {
    userId: string;
    role: 'planner' | 'contributor' | 'observer';
  };
  context: {
    workspaceId: string;
    planId?: string;
    existingTasks?: TaskSummary[];
    historyWindow?: ConversationMessage[];
  };
  entities: Record<string, unknown>;   // Intent-specific extracted data
  proposedActions: MCPAction[];
  timestamp: string;                   // ISO 8601
}

type IntentType =
  | 'CREATE_PLAN'
  | 'ADD_TASK'
  | 'UPDATE_TASK'
  | 'SUGGEST_TASKS'
  | 'ASK_SUMMARY'
  | 'MOVE_TASK'
  | 'ASSIGN_TASK';

interface MCPAction {
  tool: string;                        // Tool name (e.g., "plan.create")
  arguments: Record<string, unknown>;  // Tool-specific arguments
}
```

```go
// Go
type MCPIntentEnvelope struct {
    IntentID              string                 `json:"intentId"`
    IntentType            string                 `json:"intentType"`
    Confidence            float64                `json:"confidence"`
    NeedsClarification    bool                   `json:"needsClarification"`
    ClarificationQuestion *string                `json:"clarificationQuestion,omitempty"`
    Source                string                 `json:"source"`
    Actor                 MCPActor               `json:"actor"`
    Context               MCPContext             `json:"context"`
    Entities              map[string]interface{} `json:"entities"`
    ProposedActions       []MCPAction            `json:"proposedActions"`
    Timestamp             time.Time              `json:"timestamp"`
}

type MCPActor struct {
    UserID string `json:"userId"`
    Role   string `json:"role"`
}

type MCPContext struct {
    WorkspaceID   string        `json:"workspaceId"`
    PlanID        *string       `json:"planId,omitempty"`
    ExistingTasks []TaskSummary `json:"existingTasks,omitempty"`
}

type MCPAction struct {
    Tool      string                 `json:"tool"`
    Arguments map[string]interface{} `json:"arguments"`
}
```

## Intent Types

### CREATE_PLAN

**Trigger phrases:**
- "Plan a product launch"
- "Create a project for..."
- "I need to organize..."

**Entities:**
```typescript
{
  planName: string;
  planType: 'software' | 'event' | 'ops' | 'collection' | 'generic';
  goal: string;
  timeline?: string;
  team?: string[];
}
```

**Proposed Actions:**
```json
{
  "tool": "plan.create",
  "arguments": {
    "name": "Product Launch Q2",
    "domain": "software",
    "description": "...",
    "startDate": "2024-04-01",
    "endDate": "2024-06-30"
  }
}
```

### ADD_TASK

**Trigger phrases:**
- "Add task to..."
- "Create a task for..."
- "I need to do..."

**Entities:**
```typescript
{
  taskTitle: string;
  description?: string;
  dueDate?: string;       // Parsed from "by Friday", "next week"
  assignee?: string;      // User name/email to resolve
  priority?: string;
  planId: string;         // From context or extracted
}
```

### UPDATE_TASK

**Trigger phrases:**
- "Mark X as done"
- "Change priority of..."
- "Move task to..."

**Entities:**
```typescript
{
  taskId: string;         // Resolved from title match
  fields: {
    status?: string;
    priority?: string;
    dueDate?: string;
    assigneeId?: string;
  };
}
```

### SUGGEST_TASKS

**Trigger phrases:**
- "What tasks am I missing?"
- "Suggest tasks for..."
- "What should I add?"

**Entities:**
```typescript
{
  basedOn: 'goal' | 'existing_tasks' | 'template';
  limit: number;
}
```

**Response (not an action, returns suggestions):**
```json
{
  "suggestions": [
    {
      "title": "Create user documentation",
      "description": "...",
      "priority": "medium",
      "confidence": 0.87,
      "reasoning": "Common for software launches"
    }
  ]
}
```

### ASK_SUMMARY

**Trigger phrases:**
- "How's the project going?"
- "Give me a summary"
- "What's the status?"

**Entities:**
```typescript
{
  scope: 'plan' | 'workspace';
  timeRange: 'week' | 'month' | 'all';
}
```

**Response (read-only, no action):**
```json
{
  "summary": {
    "progress": 45.5,
    "tasksCompleted": 10,
    "tasksPending": 12,
    "overdue": 2,
    "blockers": ["API integration blocked by..."],
    "highlights": ["Design phase completed ahead of schedule"],
    "upcoming": ["Milestone 'MVP' due in 3 days"]
  }
}
```

## MCP Tools Registry

### Plan Tools

| Tool | Description | Arguments |
|------|-------------|-----------|
| `plan.create` | Create new plan | name, domain, description, startDate, endDate |
| `plan.update` | Update plan | planId, fields |
| `plan.get` | Get plan details | planId |
| `plan.list` | List plans | workspaceId, filters |
| `plan.archive` | Archive plan | planId |

### Task Tools

| Tool | Description | Arguments |
|------|-------------|-----------|
| `task.create` | Create task | planId, title, description, priority, dueDate, assigneeId |
| `task.update` | Update task | taskId, fields |
| `task.move` | Move task status | taskId, status, position |
| `task.assign` | Assign task | taskId, assigneeId |
| `task.get` | Get task details | taskId |
| `task.list` | List tasks | planId, filters |
| `task.delete` | Delete task | taskId |

### AI Tools

| Tool | Description | Arguments |
|------|-------------|-----------|
| `ai.suggest_tasks` | Generate task suggestions | planId, basedOn, limit |
| `ai.generate_plan` | Generate plan structure | goal, planType, timeline |
| `ai.summarize` | Generate summary | planId, timeRange |

## Confidence Thresholds

| Threshold | Behavior |
|-----------|----------|
| `>= 0.8` | Proceed with action, show confirmation |
| `0.6 - 0.79` | Proceed but highlight uncertainty |
| `< 0.6` | Ask clarification question |

## Draft & Approval Workflow

### 1. Intent Received
```
User: "Create a plan for the product launch"
```

### 2. Intent Processed
```json
{
  "intentId": "int_abc123",
  "intentType": "CREATE_PLAN",
  "confidence": 0.94,
  "proposedActions": [{
    "tool": "plan.create",
    "arguments": { "name": "Product Launch", ... }
  }]
}
```

### 3. Draft Created
```json
{
  "draftId": "draft_xyz789",
  "type": "plan",
  "status": "pending_approval",
  "data": {
    "name": "Product Launch",
    "domain": "software",
    ...
  },
  "expiresAt": "2024-01-02T00:00:00Z"
}
```

### 4. User Reviews
- Can **Approve** → Execute action
- Can **Edit** → Modify draft, then approve
- Can **Reject** → Discard draft

### 5. Execution & Audit
```json
{
  "auditId": "aud_456",
  "timestamp": "2024-01-01T12:00:00Z",
  "userId": "user_123",
  "workspaceId": "ws_456",
  "intentId": "int_abc123",
  "action": {
    "tool": "plan.create",
    "arguments": { ... }
  },
  "result": {
    "planId": "plan_789",
    "status": "created"
  },
  "status": "success"
}
```

## Audit Log Schema

```sql
CREATE TABLE mcp_audit_log (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    timestamp TIMESTAMPTZ DEFAULT NOW(),
    user_id UUID NOT NULL REFERENCES users(id),
    workspace_id UUID NOT NULL REFERENCES workspaces(id),
    intent_id UUID,
    intent_type VARCHAR(50),
    intent_envelope JSONB,
    action_tool VARCHAR(100),
    action_arguments JSONB,
    result JSONB,
    status VARCHAR(50) NOT NULL,  -- success, failed, rejected, expired
    error_message TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_mcp_audit_user ON mcp_audit_log(user_id);
CREATE INDEX idx_mcp_audit_workspace ON mcp_audit_log(workspace_id);
CREATE INDEX idx_mcp_audit_timestamp ON mcp_audit_log(timestamp DESC);
```

## Prompt Templates

### System Prompt (All Agents)

```
You are GoPlan AI, a planning assistant for project management.

Rules:
1. Output must be valid JSON matching the MCPIntentEnvelope schema
2. Never create or update data directly - always propose actions
3. If confidence < 0.6, set needsClarification: true
4. Extract all relevant entities from user input
5. Be concise in descriptions
6. Respect user permissions - check role before proposing actions

Available intent types: CREATE_PLAN, ADD_TASK, UPDATE_TASK, SUGGEST_TASKS, ASK_SUMMARY
```

```
User: {{actor.userId}}

{{/each}}

Recent Messages:
{{#each context.historyWindow}}

{{/each}}
```

## Testing Contracts

### Unit Test: Intent Classification

```go
func TestClassifyIntent_CreatePlan(t *testing.T) {
    tests := []struct {
        input    string
        expected string
        minConf  float64
    }{
        {"Plan a product launch", "CREATE_PLAN", 0.8},
        {"Create project for marketing", "CREATE_PLAN", 0.8},
        {"I need to organize an event", "CREATE_PLAN", 0.7},
    }

    for _, tt := range tests {
        result := ClassifyIntent(tt.input)
        assert.Equal(t, tt.expected, result.IntentType)
        assert.GreaterOrEqual(t, result.Confidence, tt.minConf)
    }
}
```

### Integration Test: Full Flow

```go
func TestMCPFlow_CreateTask(t *testing.T) {
    // 1. Send intent
    resp := POST("/mcp/intent", `{
        "input": "Add task to review designs by Friday",
        "context": {"planId": "plan_123"}
    }`)
    assert.Equal(t, "ADD_TASK", resp.IntentType)
    assert.True(t, resp.RequiresApproval)

    // 2. Approve
    approved := POST("/mcp/intent/"+resp.IntentID+"/approve", nil)
    assert.NotEmpty(t, approved.Result.TaskID)

    // 3. Verify task created
    task := GET("/tasks/" + approved.Result.TaskID)
    assert.Equal(t, "Review designs", task.Title)
}
```
